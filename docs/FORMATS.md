# Data formats (v1)

All files are JSON, written under `<app>/.lowrail/`.

## facts.json — what the booted app looks like

Written by `gem/exe/lowrail-facts` (run inside the app with `bundle exec`,
`RAILS_ENV=test`, after `Rails.application.eager_load!`). Raw observations
only; classification (e.g. "generated by `has_many`") happens in Rust, where
Prism can look at the source span.

```json
{
  "format": 1,
  "ruby_description": "...", "rails_version": "8.1.4", "app_root": "/abs",
  "yjit": false,
  "gems": [{"name": "activerecord", "version": "8.1.4", "path": "/abs/gems/activerecord-8.1.4"}],
  "load_path_features": ["/abs/file.rb", "..."],
  "modules": [{
    "name": "Article", "kind": "class", "superclass": "ApplicationRecord",
    "ancestors": ["Article", "Article::GeneratedAssociationMethods", "..."],
    "singleton_ancestors": ["#<Class:Article>", "..."],
    "const_source_location": "/abs/app/models/article.rb:1",
    "methods": [{
      "name": "title", "singleton": false, "visibility": "public",
      "owner": "Article::GeneratedAttributeMethods",
      "source_location": "/abs/gems/activemodel-8.1.4/lib/active_model/attribute_methods.rb:123",
      "parameters": [["req", "x"]],
      "iseq_kind": "method"   // method | block (define_method) | eval | cfunc | attr | none
    }]
  }],
  "models": [{
    "name": "Article", "table": "articles", "primary_key": "id",
    "columns": [{"name": "title", "type": "string", "sql_type": "varchar", "null": false, "default": null}],
    "associations": [{"macro": "has_many", "name": "comments", "class_name": "Comment",
                      "foreign_key": "article_id", "options": {"dependent": "destroy"}}],
    "callbacks": {"save": [{"kind": "before", "filter": "normalize", "conditions": false}]}
  }],
  "controllers": [{"name": "ArticlesController", "actions": ["index"],
                   "callbacks": [{"kind": "before", "filter": "set_article", "conditions": true}]}],
  "routes": [{"verb": "GET", "path": "/articles(.:format)", "name": "articles",
              "controller": "articles", "action": "index"}]
}
```

Methods are listed per module for the methods **owned by or visible on** that
module: `instance_methods(false)` + `private_instance_methods(false)` on the
module and its singleton class, so the dump stays linear in the app size.
Resolution facts (`Article#title` → owner) for a receiver are derived from the
ancestors chain.

## manifest.json — what the runtime gem loads

Written by `lowrail build` (via `gem/exe/lowrail-compile`).

```json
{
  "format": 1,
  "ruby_description": "...",
  "compile_option": "<sha256 of sorted RubyVM::InstructionSequence.compile_option>",
  "files": {"/abs/app/models/article.rb": {"iseq": "iseq/<sha>.bin", "source_sha256": "..."}},
  "units": [{
    "id": 0, "file": "/abs/app/models/article.rb", "method": "Article#summary", "pass": "...",
    "facts": [{"receiver": "Article", "method": "title", "singleton": false,
               "owner": "Article::GeneratedAttributeMethods",
               "source_location": "/abs/...:123", "visibility": "public"}]
  }]
}
```

## build input for lowrail-compile — `units.json`

```json
{"out": "/abs/app/.lowrail", "files": [{"path": "/abs/app/models/article.rb",
  "lowered": "/abs/app/.lowrail/src/<sha>.rb"}], "units": [ ...as in manifest... ]}
```

`lowrail-compile` compiles each lowered source with
`RubyVM::InstructionSequence.compile(src, path, path, 1)` (path = original
absolute path), writes binaries, then atomically writes `manifest.json`.

## verify outcomes — `outcomes-<mode>.json`

Written by the Minitest reporter (`LOWRAIL_OUTCOMES=path`):
`{"tests": {"ArticleTest#test_x": {"result": "pass|fail|error|skip", "failure": "Class: first line"}}, "unit_hits": {"0": 12}}`.
