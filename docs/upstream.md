# Upstream findings

Profiling findings that are best fixed in the gem that causes them, so every
user of that gem benefits. Lowrail passes cover apps on older versions; the
upstream fix removes the cause.

| Finding | Measured | Gem / version | Proposed fix | Status |
|---|---|---|---|---|
| `Manifest#digest` re-reads and MD5-hashes the Vite manifest on every call; with a lazy Inertia version proc that is every request | ~279 µs/call; 12.8–15.8 % self per Inertia JSON request (private app, aggregates only). Version computed once at boot: two pages −19 % and −23 %, one within noise (production mode, 5 interleaved pairs) | `rails_vite` 0.3.0 | Memoize the digest outside `Rails.env.local?` like `Manifest#data`; do not cache `"no-manifest"` | [issue #56](https://github.com/skryukov/rails_vite/issues/56), [PR #57](https://github.com/skryukov/rails_vite/pull/57) open; the private app sets the version once at boot meanwhile (merged) |
| CSP importmap processing (`InlineScriptHashes#script_locations`) on every cached page | M0: 34.8% inclusive; 90 joins / request for one location. Method micro: 1265.45 → 26.56 µs; instruction A/A failed, not an accepted request-speed claim | **Campfire app code**, not an uncached importmap-rails 2.2.2 / Propshaft 1.3.2 resolver | Bounded process-local derived-location cache keyed by complete JSON, asset directory and current request origin; keep policy/nonce/resolver live | [App patch and issue/PR drafts](upstream-drafts/campfire.md), **unpublished**. [Investigation](passes/importmap.md): whole-method Lowrail reuse refused under Rails' regexp timeout; no new pass or setup hook |
| `SchemaContext::Attributes#builder` builds a new `AttributeSet::Builder` and a primary-key defaults subset on every `attributes_builder` call (about 4 objects per loaded row) | Campfire `Message` load-only: 60.8 → 37.2 µs at 20 rows with a guarded per-model variant (`--ar-instantiate`) | Rails main at e3d5c569 (Campfire's pin) | none needed | **already fixed upstream**: [rails/rails@f126797d45](https://github.com/rails/rails/commit/f126797d45) (2026-10-15) builds the builder once. Campfire's pin predates it; the pass's alpha gain will disappear on current main |
