Share unescape between Utils and QueryParser

Rack::Utils.unescape and QueryParser#unescape duplicated the decoding
logic. Move it into a Rack::Unescape module in its own file, which
query_parser.rb and utils.rb require and both include, together with
the uri and cgi/escape requires it needs. Utils makes it a module
function as before, so Rack::Utils.unescape still works, including
Utils still gives a private unescape, and QueryParser subclasses can
still override it. Its documentation stays in Utils as RDoc and YARD
method entries.

utils.rb is a binary source file, so the ArgumentError that
Utils.unescape raised for an invalid %-encoding of an ASCII-only string
had a binary message. It now has the encoding of URI's message, as
QueryParser#unescape's already did.
