# ZJIT: Find caller-saved survivors without scanning every interval per CCall

`handle_caller_saved_regs()` scans every interval at every C call to find registers that need spilling. This PR indexes register live ranges by the sorted C call positions, then reads each call's slice from one flat table. It avoids an intermediate `Vec` per call, reuses the survivor buffers, and preserves survivor order. It does not split intervals.

On ruby-bench, median ZJIT compilation time is lower on lobsters and shipit; railsbench is inconclusive. These are `compile_time_ns` statistics, not benchmark iteration times:

```diff
 lobsters
-compile_time_ns: 5,117,946,763
+compile_time_ns: 4,774,260,682
 shipit
-compile_time_ns: 4,019,669,732
+compile_time_ns: 3,894,138,988
```

No run-time improvement is demonstrated.
