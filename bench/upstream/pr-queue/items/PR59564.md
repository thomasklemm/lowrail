# Build the preloader's working Arrays in place

Every `preload`, and every `includes` that preloads, runs `Preloader::Batch#call`, which loops until every branch is loaded. On each pass it asks every branch for its future classes and runnable loaders, and those answers are rebuilt from copies: `Branch#future_classes` builds an Array, appends to a copy and `uniq`s it into a third, and `#immediate_future_classes` and `#target_classes` copy `likely_reflections` with `reject` before mapping it.

All of these Arrays are built fresh in the same method, so this builds them in place with `concat`, `delete_if`, `map!` and `uniq!`. Order and contents are unchanged, and no Array that a caller, a loader or another branch holds is mutated.
