# Compare tag attribute types with `==` in `tag_options`

`tag_options` checks every attribute's type with `type != :aria && type != :class`. The type is `nil` for most
attributes and a Symbol for the others. YJIT inlines `==` on nil and Symbols, but for `!=` it calls
`BasicObject#!=`, which calls `==` through `rb_funcall`. So under YJIT, most attributes make two such calls before
their value is looked at.

This writes the same condition with `==` and one negation. It calls `==` on the same nil and Symbols and `is_a?` on
the attribute value in the same cases, so the attributes come out the same.

```ruby
require "bundler/inline"

gemfile do
  source "https://rubygems.org"
  gem "rails", path: "."
  gem "benchmark-ips"
end

require "action_view"

view = ActionView::Base.empty

Benchmark.ips do |x|
  x.report("tag.a") { view.tag.a("Jane Doe", href: "/users/42", class: "author-link", title: "Jane Doe") }
  x.report("content_tag") { view.content_tag(:span, "Jane & John", class: "byline") }
end
```
