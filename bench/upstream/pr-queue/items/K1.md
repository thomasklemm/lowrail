# Avoid rebuilding attribute names in `LazyIndexedAttributeSet#keys`

In #59141, `LazyIndexedAttributeSet#row_keys` became every name in the set's indexes, which already cover every typed attribute of the model. #59833 removed `cached_names` from the union in `#keys`, and the `@ctx.type_keys` left in it adds nothing either: `row_keys | @ctx.type_keys` always equals `row_keys`, but still builds another array, and for more than 16 names a hash, on every call. Dirty tracking and `attribute_names` call `#keys` on every `changed?`, `save`, `inspect` and `serializable_hash`. `materialize`, which `save` and `dup` run, likewise walked the type keys a second time.

This drops the union and the second walk, and with them the context's unused `type_keys`. `#keys` returns the same names in the same order, as `#to_hash` already assumes.
