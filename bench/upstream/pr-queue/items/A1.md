# Don't serialize owner-condition binds for associations without a scope

Since #59836, `keep_owner_conditions` compares the where clauses before and after the association scope with
`WhereClause#-`, for every association scope and join scope, also when the association has no scope. `Array#-`
hashes both sides once each has more than 16 predicates, and `QueryAttribute#==` and `#hash` serialize the bind
value, so binds are serialized earlier than in 8.1. A join whose target default scope has 17 conditions, one of them
an out-of-range integer, raises `ActiveModel::RangeError` instead of matching no rows, and a type whose
serialization depends on context serializes differently.

This keeps the where clauses and compares them only when a scope was merged, after the scope ran. Without a scope
nothing is compared, as on 8.1. The added tests fail on main and pass on 8.1. It also saves five differences per association load
and three per join scope:
