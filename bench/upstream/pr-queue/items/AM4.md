# Let the Action Mailer test helper load without Active Job

Since Action Mailer no longer depends on Active Job (#59820, unreleased), an application can use Action Mailer without the `activejob` gem, but `ActionMailer::TestHelper` still requires it. The railtie includes that helper in every integration test, so such an application raises `LoadError: cannot load such file -- active_job` as soon as `ActionDispatch::IntegrationTest` loads, and every `ActionMailer::TestCase` does too. [Discourse](https://github.com/discourse/discourse/blob/033c474926c78398869d5dd0fbd729f4c3709594/Gemfile#L11-L17) lists the frameworks it uses without Active Job, and its test suite fails this way on Rails main.

This requires Active Job only when it is available and includes its test helper only then. Without it, `capture_emails`, and so `assert_emails` with a block, runs the block directly. The assertions for enqueued emails still need Active Job.
