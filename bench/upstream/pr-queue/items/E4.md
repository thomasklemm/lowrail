# Require minitest 5.18 in Active Support

Since 23420be739 added the unconditional `assert_not_pattern` alias, Active Support needs minitest's `refute_pattern`, which arrived in 5.18. Bundler can still select an older minitest that satisfies the declared `>= 5.1`, and then `ActiveSupport::TestCase` fails to load:

```
undefined method 'refute_pattern' for class 'ActiveSupport::TestCase' (NameError)
```

active_model_serializers 0.10.16's suite hits this through its [development dependency](https://github.com/rails-api/active_model_serializers/blob/6934c8bd31f4025fe7548a07d50a82f18df8e689/active_model_serializers.gemspec#L42) on `minitest < 5.11`.

This declares `minitest >= 5.18`, so Bundler reports a conflict for such pins instead, and other applications resolve a newer minitest. On Ruby 4, resolution must select a later Ruby-compatible release, because minitest 5.18.0 declares Ruby < 4.0.
