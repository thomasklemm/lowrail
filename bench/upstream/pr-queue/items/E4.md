# Fix Active Support test loading with older minitest

Loading `ActiveSupport::TestCase` raises `NameError` with older minitest releases that still satisfy Active Support's declared dependency. This affects active_model_serializers' test suite through its [development dependency](https://github.com/rails-api/active_model_serializers/blob/6934c8bd31f4025fe7548a07d50a82f18df8e689/active_model_serializers.gemspec#L42) on an older minitest.

Define `assert_not_pattern` only when minitest provides `refute_pattern`, following the existing capability checks for minitest API differences. This restores compatibility without raising the minimum dependency.
