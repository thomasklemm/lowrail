# Note in the upgrade guide that link_to and button_to moved to NavigationHelper

This adds a section to "Upgrading from Rails 8.1 to Rails 8.2" for a change on main that breaks existing apps and that the guide doesn't mention yet. #55410 moved `link_to`, `button_to` and `current_page?` to `NavigationHelper`, so classes that include `UrlHelper`, `FormTagHelper` or `FormHelper` without it lose them, as in [Redmine's hook listeners](https://github.com/redmine/redmine/blob/41cd39c24a9f913a69c8a9ec4cbc128a6600fbce/lib/redmine/hook/view_listener.rb#L32), which plugins use to build links. avo already ships the include this note describes ([avo-hq/avo#4808](https://github.com/avo-hq/avo/pull/4808)).
