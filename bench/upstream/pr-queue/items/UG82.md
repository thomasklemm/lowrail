# Add four notes to the Rails 8.2 upgrade guide

This adds four sections to "Upgrading from Rails 8.1 to Rails 8.2", each for a change on main that breaks existing apps and that the guide doesn't mention yet. They are separate commits, so each can be taken on its own:

* `link_to`, `button_to` and `current_page?` moved to `NavigationHelper` (#55410): classes that include `UrlHelper` or `FormHelper` without it lose them, as in [Redmine's hook listener](https://github.com/redmine/redmine/blob/41cd39c24a9f913a69c8a9ec4cbc128a6600fbce/lib/redmine/hook/view_listener.rb#L32).
* `Rack::Sendfile` is omitted when `x_sendfile_header` is unset (#56915), so `insert_before Rack::Sendfile` then raises on boot, as in [Redmine](https://github.com/redmine/redmine/blob/41cd39c24a9f913a69c8a9ec4cbc128a6600fbce/config/application.rb#L79).
* Loading fixtures on PostgreSQL 18.4+ acquires more locks (#57378): parallel test workers loading fixtures into databases with a few hundred foreign keys can fail with `out of shared memory`.
* Sidekiq 8.0.3 or later is needed (#56518): older releases, including the 7.3.3+ that the 8.1 deprecation recommends, can fail to load Sidekiq's adapter, which sidekiq/sidekiq#6669 fixed in 8.0.3.
