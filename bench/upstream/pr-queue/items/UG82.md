# Add five notes to the Rails 8.2 upgrade guide

This adds five sections to "Upgrading from Rails 8.1 to Rails 8.2", each for a change on main that breaks existing apps and that the guide doesn't mention yet. They are separate commits, so each can be taken on its own:

* `link_to`, `button_to` and `current_page?` moved to `NavigationHelper` (#55410): classes that include `UrlHelper`, `FormTagHelper` or `FormHelper` without it lose them. avo already ships the include this note describes ([avo-hq/avo#4808](https://github.com/avo-hq/avo/pull/4808)). Affected on main are [Redmine's hook listeners](https://github.com/redmine/redmine/blob/41cd39c24a9f913a69c8a9ec4cbc128a6600fbce/lib/redmine/hook/view_listener.rb#L32), Decidim's presenters and events ([example](https://github.com/decidim/decidim/blob/80149bbba83a3c477172d113d21e22115c901e54/decidim-core/app/presenters/decidim/user_presenter.rb#L8)) and every cells-rails cell ([`FormHelper`](https://github.com/trailblazer/cells-rails/blob/77ff22ae8f94472cf477672ca2f0c86757d627d8/lib/cell/railtie.rb#L49)).
* `Rack::Sendfile` is omitted when `x_sendfile_header` is unset (#56915), so `insert_before Rack::Sendfile` then raises on boot, as in [Redmine](https://github.com/redmine/redmine/blob/41cd39c24a9f913a69c8a9ec4cbc128a6600fbce/config/application.rb#L79).
* Loading fixtures on PostgreSQL 18.4+ acquires more locks (#57378): parallel test workers loading fixtures into databases with a few hundred foreign keys can fail with `out of shared memory`.
* Sidekiq 8.0.3 or later is needed (#56518): older releases, including the 7.3.3+ that the 8.1 deprecation recommends, can fail to load Sidekiq's adapter, which sidekiq/sidekiq#6669 fixed in 8.0.3. Sidekiq must also be required before initialization, including when its Gemfile entry uses `require: false`.
* HTML elements must close in the branch that opens them (#58721): Herb pairs tags within each branch of Ruby control flow, so a template that opens an element in one branch or loop iteration and closes it in another no longer compiles, even when the HTML it renders is balanced. Affected on main are [lobsters' user tree](https://github.com/lobsters/lobsters/blob/36f631c083baf1aa1bf0cf7ed22a8e9fe277c41c/app/views/users/tree.html.erb#L22-L38), [Discourse's topic page](https://github.com/discourse/discourse/blob/b2d1791995a03498e183d2929452b762af99b305/app/views/topics/show.html.erb#L64-L67) and [Redmine's bulk edit form](https://github.com/redmine/redmine/blob/4dba4a79238191d617c4809b25e3818f966f5406/app/views/issues/bulk_edit.html.erb#L202-L204).
