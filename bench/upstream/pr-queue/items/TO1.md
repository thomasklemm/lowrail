# Write tag attributes into the tag's own string

`tag` and void elements such as `tag.input` and `tag.img` built their attributes in a String of their own with `tag_options`, then interpolated that String into the tag. Now they start the tag's String with its name and pass it to `tag_options`, which appends the attributes to it, so each such tag with attributes allocates one String fewer. Called without that argument, `tag_options` returns a new String as before.

This covers the `*_tag` input helpers, the hidden inputs that forms and `button_to` add, form builder inputs such as `checkbox`, and `image_tag` with the link, source and meta tags.

Wall time per call:

| | Ruby 4.0.10 with YJIT | Ruby master with ZJIT |
| --- | ---: | ---: |
| `tag.input` | −5.7% | −4.1% |
| `text_field_tag` | −2.5% | −2.4% |
| `submit_tag` | −2.2% | −1.5% |
| `image_tag` | −1.5% | −2.1% |
| `form.checkbox` | −1.7% | −1.5% |

Objects per request drop by 21 on an article page (1,942 to 1,920), by 69 on a book list page (4,355 to 4,286) and by 53 on a large edit form (22,566 to 22,513).
