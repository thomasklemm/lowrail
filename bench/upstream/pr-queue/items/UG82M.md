# Note in the upgrade guide that Action Mailer no longer loads Active Job

An app that lists its frameworks in `config/application.rb` and requires `action_mailer/railtie` without `active_job/railtie` got the Active Job railtie through Action Mailer's until #59820. On main it doesn't, so setting `config.active_job.queue_adapter` raises `NoMethodError` on boot. A gem that sets `config.active_job` when Active Job loads fails the same way, such as [money-rails 3.0.0](https://github.com/RubyMoney/money-rails/blob/f5e2af72988a684ed88904ddc7f39974cc7d23ee/lib/money-rails/hooks.rb#L42), which makes such an app raise on boot when eager loading. This adds a section to "Upgrading from Rails 8.1 to Rails 8.2" that says to require the Active Job railtie explicitly.
