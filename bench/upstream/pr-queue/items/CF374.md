# Parse the CSP importmap base URL once per request

CSP is rebuilt before the page-cache lookup. With the current 90 import pins, `script_locations` parses the same request base URL 90 times.

This parses the common base once with `URI.join`, reuses it in the existing per-import joins, and reads the request origin and host once, so a call parses 91 URIs instead of 180. Every import still goes through the same URI parser and joins don't mutate the base, so ordering, deduplication, the asset-directory selection and the exact-path fallback stay the same; the CSP headers and full HTML of a room page are byte-identical.

`script_locations` per call, Ruby 4.0 with YJIT:

| | Before | After |
| --- | ---: | ---: |
| CPU time | 1,682 µs | 678 µs |
| Objects | 5,696 | 2,306 |
