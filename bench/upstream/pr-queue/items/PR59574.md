# Deprecate a positional table name in Arel::Table.new

`Arel::Table.new(:users)`, which Rails 8.1 and earlier accept, raises `ArgumentError` on main, because #57829 made the table name the `name:` keyword. Arel is nodoc, but gems and apps call it: flipper 1.4.2 fails in `Flipper::Adapters::ActiveRecord#get_all`, and so do Discourse and Docuseal; the comments on #57829 report Intercom and GitHub.

As suggested in #57829, a positional name, as in `Arel::Table.new(:users)` or `Arel::Table.new(nil, klass: User)`, now keeps working with a deprecation warning and behaves exactly as `name:`. A call passing both uses the positional name; neither the Rails 8.1 signature nor main's allows both. `as:`, `klass:` and `type_caster:` were already keywords, so nothing else changes.
