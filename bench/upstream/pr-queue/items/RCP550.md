# Mark Performance/ChainArrayAllocation as unsafe and document ownership

`Performance/ChainArrayAllocation` recommends mutating an intermediate array, but cannot prove that the result is mutable and exclusively owned. An override can retain or freeze it. The new example shows `uniq.map!` changing an array retained by an `Array` subclass.

This documents that ownership boundary, keeps the first operation non-mutating in the ordinary Array example, and sets `Safe: false`. Detection is unchanged, the cop remains disabled by default, and it still has no autocorrection. When explicitly enabled, the cop is now skipped by `--safe`; normal runs are unchanged.

Related ownership discussion: #432. This does not implement or close that proposed reassignment cop.
