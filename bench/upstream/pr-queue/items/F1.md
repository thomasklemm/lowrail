# Return same-object ar_table hits without calling ar_equal

Hits on the first keys of a small Hash cost more on master than on 4.0. Since #18222, GCC compiles `ar_find_entry_hint` as its own function, which saves registers for its slow-path loop on every call; since #18476, `ar_equal` checks the identity flag and calls `rb_any_cmp` out of line. So a Symbol hit, such as `options[:class]` on a keyword-splat Hash, makes three calls to find the key object already in the slot.

This keeps the SWAR search and identity hashes, and returns the first matching slot at once when it holds the key itself, which `rb_any_cmp` and identity hashes both treat as equal without running Ruby code. Other cases run the previous code, now `ar_find_entry_hint_slow`.
