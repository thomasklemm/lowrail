# ZJIT: Send Symbol block arguments directly

Under ZJIT, a send such as `foo(&:sym)` stays dynamic. This handles the Symbol case left by #18180 (Shopify/ruby#1014).

A static Symbol block argument now compiles to `SendDirect` for ISEQ callees and to `CCallWithFrame` or `CCallVariadic` for C functions such as `Array#reject`, with the Symbol as the callee frame's block handler. The send is specialized only while `Symbol#to_proc` is basic and no `Ruby::Box` has been created, and a guard exits to the interpreter when the caller's cref has refinements. The callee's `yield` is unchanged.

The first commit builds on Rafael Mendonça França's [`zjit-perf/blockarg-direct-send`](https://github.com/Shopify/ruby/tree/zjit-perf/blockarg-direct-send) branch, and he is its author. His branch also sends forwarded block parameters directly; k0kubun's [`bac34035c7`](https://github.com/k0kubun/ruby/commit/bac34035c7) in Shopify/ruby#1030 covers that part.

`attr-read` runs the attribute reads of rails/rails#59803, `symbol-block` runs `one(i, &:itself)` and `[1, 2, 3].map(&:itself)`, and `master-again` is master a second time.
