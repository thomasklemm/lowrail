# Use Solid Cache for the production Rails cache

Moves the production `Rails.cache` from Redis to Solid Cache, in its own SQLite database that `db:prepare` creates. It's the first of three steps toward running Campfire without Redis: #346 moves the jobs and #347 Action Cable.

Entries aren't copied, so the cache starts cold after the upgrade. The cache database keeps SQLite's own WAL checkpoints, since the checkpoint contender only checkpoints the primary database. The restore hook deletes it rather than keep a copy taken from a running volume; it refills on demand. The HTTP benchmark now prepares the databases before starting Puma, so seeds made before a new database still boot.
