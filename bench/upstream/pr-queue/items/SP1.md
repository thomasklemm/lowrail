# Note in the upgrade guide that default_url_options is frozen unless configured

#58483 froze the `default_url_options` Hash that controllers, mailers and every other class including the URL helpers start with. Neither the CHANGELOG nor the upgrade guide mentions it. Running Spree's test suite on Rails main, I found that code that sets a host in place now raises when the application hasn't configured the options:

```ruby
ActionMailer::Base.default_url_options[:host] = "shop.example.com"
# 8.1:  sets the host
# main: FrozenError: can't modify frozen Hash: {}
```

Callers that fail on Rails main:

* Spree 6.0.5's [`BaseMailer#ensure_default_action_mailer_url_host`](https://github.com/spree/spree/blob/9d9783cee63f18d3182100c35ef91d8775c84992/spree/core/app/mailers/spree/base_mailer.rb#L182), which [`mail` calls](https://github.com/spree/spree/blob/9d9783cee63f18d3182100c35ef91d8775c84992/spree/core/app/mailers/spree/base_mailer.rb#L65) for every email of a store with a storefront URL;
* rails_admin 3.3.1's [`spec_helper.rb`](https://github.com/railsadminteam/rails_admin/blob/ab5ae554288314e406b2e10ece556c342cec40a4/spec/spec_helper.rb#L44), when the suite loads;
* rspec-rails 8.0.5's [feature example group](https://github.com/rspec/rspec-rails/blob/b7225ca52449c40b17acf535cc451a47c1d3d18b/lib/rspec/rails/example/feature_example_group.rb#L19) (fixed in 8.1.0).

This adds a section to "Upgrading from Rails 8.1 to Rails 8.2" with the three replacements (configure the options, assign a new Hash, override the method) and notes that `routes.default_url_options` is unaffected.
