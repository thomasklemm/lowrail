# Note in the upgrade guide that default_url_options is frozen by default

#58483 froze the `default_url_options` Hash that controllers, mailers and every other class including the URL helpers start with. Neither the CHANGELOG nor the upgrade guide mentions it. Code that sets a host in place now raises when the application hasn't configured the options, which showed up in Spree's test suite on Rails main:

```ruby
ActionMailer::Base.default_url_options[:host] = "shop.example.com"
# 8.1:  sets the host
# main: FrozenError: can't modify frozen Hash: {}
```

Callers that fail on Rails main:

* Spree 6.0.6's [`BaseMailer#ensure_default_action_mailer_url_host`](https://github.com/spree/spree/blob/314dcb7784475b3b02ab482ba37882ff100f1365/spree/core/app/mailers/spree/base_mailer.rb#L182), which [`mail` calls](https://github.com/spree/spree/blob/314dcb7784475b3b02ab482ba37882ff100f1365/spree/core/app/mailers/spree/base_mailer.rb#L65) for every email of a store with a storefront URL;
* rails_admin 3.3.1's [`spec_helper.rb`](https://github.com/railsadminteam/rails_admin/blob/ab5ae554288314e406b2e10ece556c342cec40a4/spec/spec_helper.rb#L44), when its suite loads.

This adds a section to "Upgrading from Rails 8.1 to Rails 8.2" with the three replacements (configure the options, assign a new Hash, override the method) and notes that `routes.default_url_options` is unaffected.
