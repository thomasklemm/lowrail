# Retry interrupted jobs that are safe to run again

Stacked on #346; review only the last commit: [compare](https://github.com/thomasklemm/once-campfire/compare/feat/solid-queue-cutover...feat/retry-interrupted-jobs).

With #346, a job that's still running when its worker is stopped or killed is marked failed (`ProcessExitError`, `ProcessMissingError` at the next boot, or `ProcessPrunedError` once the dead worker is pruned) and has to be retried by hand. Solid Queue [deliberately doesn't retry these](https://github.com/rails/solid_queue/blob/v1.7.0/README.md#jobs-interrupted-by-non-graceful-process-death), since the job may be what killed the worker, and leaves a recovery policy for idempotent jobs to the app.

This adds a recurring task that retries such a job every minute, up to three times, but only for jobs that are safe to run again from the start:

| Job | Retried | Why |
| --- | --- | --- |
| `Room::DestroyJob` | yes | messages go one at a time and the room last, so a rerun picks up where it stopped |
| `ActiveStorage::PurgeJob` | yes | a purged blob is discarded on rerun |
| `RemoveBannedContentJob` | no | the user may have been unbanned by the time it reruns |
| `Bot::WebhookJob`, `Room::PushMessageJob` | no | would deliver twice |
| `Message::BroadcastUnreadRoomJob`, broadcasts | no | would broadcast twice |

`FailedExecution#retry` resets the job's execution count, so the task does the retry itself and counts it in `executions`. Jobs that failed with an error of their own are left alone. It's a sweep rather than a `fail_many_claimed.solid_queue` subscriber, so it also catches failures whose event was missed (the supervisor itself killed, say) and spaces retries a minute apart instead of rerunning a job that may have killed its worker straight away.

The test environment gets a queue database so the test can use real Solid Queue records; jobs still run on the test adapter.

## Verification

Room with 10,000 messages, `Room#destroy_later`, then SIGTERM to `bin/boot` 5 s in, restart, and a check of the room:

| Head | After restart |
| --- | --- |
| #346 | job failed, room and ~3,600 messages left |
| this PR | room gone within 100 s |
| this PR, SIGKILL instead | room gone ~6 min after restart (5 min until the dead worker is pruned, then the next run) |
