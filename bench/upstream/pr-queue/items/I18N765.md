# Build the fallback options without a keyword Hash

`Backend::Fallbacks#translate` copies the options for the fallback lookups with `options.merge(:fallback_in_progress => true, fallback_original_locale: locale)`. The two keywords are collected into a Hash first, so every translation through Fallbacks allocates two Hashes here.

This copies the options with `options.dup` and stores the two keys instead, avoiding the temporary keyword Hash without changing the caller's options. For ordinary Hashes the copy retains the default, `compare_by_identity` and key order.

Custom options-Hash `merge`, duplication or `[]=` hooks can behave differently on direct backend calls; `I18n.t` passes a fresh plain Hash without those hooks.

Objects allocated per call with `I18n::Backend::Fallbacks` included, Ruby 4.0, no JIT:

| Call | Before | After |
| --- | ---: | ---: |
| `I18n.t(:hello)` | 13 | 12 |
| `I18n.t(:greet, name:)` | 21 | 20 |
| `I18n.l(time)` | 52 | 49 |
