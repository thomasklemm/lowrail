# Replace Redis with Solid Cable

Stacked on #345 and #346, which should merge first; only the last commit (`260c050`) is new here.

With the cache on Solid Cache and the jobs on Solid Queue, Action Cable is the last thing using Redis. It moves to Solid Cable, in its own SQLite database, and Redis goes: the server process, the `redis` and `kredis` gems, the Debian package, `bin/setup`'s container and CI's service.

Development uses Solid Cable as well, because `bin/dev` runs several Puma workers and a broadcast has to reach sockets held by the others. Broadcasts are transient, so the restore hook deletes the cable database together with the cache's.
