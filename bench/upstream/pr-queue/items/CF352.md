# Skip needless work in the text message presentation filters

This change reduces avoidable work in text-message presentation filters while preserving the rendered output.

- Check for an Open Graph embed before converting message content to plain text. That conversion resolves and renders attachments, including mentions, even when there is no unfurled link to compare.
- Replace the long negative CSS selector used by `SanitizeTags` with one element traversal and a set lookup. Disallowed elements and their contents are still removed.

Cold production-mode renders of an 80-message room, one process, medians:

| Workload | Before | After |
| --- | ---: | ---: |
| Room | 112.3 ms | 103.8 ms |
| Older page | 114.3 ms | 101.3 ms |
| Search | 235.8 ms | 201.8 ms |

Presentation output and filtered HTML are byte-identical across unfurls (Trix and Lexxy), mentions, formatting, tables and unsafe markup. New tests cover forbidden tags nested inside allowed elements and the reverse, and a message without an unfurl that skips the plain-text conversion.
