# Skip needless work in the text message presentation filters

Every text message goes through the solo-unfurled-link check, which converts the whole body to plain text, rendering each attachment and mention, just to compare it with an unfurled link most messages don't have. The check now converts only when the message has an unfurled link.

`SanitizeTags` removed disallowed elements with a selector of fifty `:not()` clauses. It now walks the elements once and looks each name up in a set, removing the same elements. The filtered HTML is byte-identical.

Filtering one message, averaged over plain, formatted and mention messages, Ruby 4.0, no JIT:

| Before | After |
| ---: | ---: |
| 680 µs | 250 µs |
