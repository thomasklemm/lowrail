# Pass block literals instead of Symbol blocks in `LazyIndexedAttributeSet`

Since #59141, the first read of an attribute of a loaded record through its reader or `id` goes through `cast_value(name, index, &:value!)` in `LazyIndexedAttributeSet#fetch_value_at!` or `#value_at!`, and every `dup` of a record runs `map(&:deep_dup)`. YJIT and ZJIT don't specialize a call whose block argument is a Symbol, so each of these calls falls back to a generic send.

This passes block literals that call the same methods. They run at the same moments on the same attributes, so values and exceptions are the same; an exception raised inside the block has one more frame in its backtrace.

Callgrind instructions per call against main, 30-column records, Ruby 4.0 without JIT and with YJIT, ZJIT on Ruby master:

| | no JIT | YJIT | ZJIT |
|---|---:|---:|---:|
| build 10 records from a query result, read each attribute once | −2.5% | −7.5% | −20.6% |
| `dup` of a loaded record | −1.9% | −5.7% | −12.3% |
