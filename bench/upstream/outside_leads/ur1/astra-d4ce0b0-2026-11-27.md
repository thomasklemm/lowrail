## Demonstrated message error and smallest fix

The message says that on TruffleRuby, “CGI.unescape is slower than the `gsub` and keeps the String
subclass that String#b returns there.” **The subclass-preserving method is `CGI.unescapeURIComponent`,
not `CGI.unescape`.** Executed on actual TruffleRuby 40.0.0:

```ruby
require 'cgi/escape'
class S < String; end
s = S.new('a').b
p [s.class, CGI.unescape(s, Encoding::ASCII_8BIT).class,
   CGI.unescapeURIComponent(s, Encoding::ASCII_8BIT).class]
# [S, String, S]
```

Empty, plus-containing and percent-containing strings produce the same class triple. The retained
`truffle_classes.rb` and `truffle-cgi-result-classes-replay.txt` reproduce it. Smallest fix: separate the
clauses and attribute subclass preservation to `CGI.unescapeURIComponent`. This needs only a message
amendment, not a source change. This probe does not measure the separate speed claim.
