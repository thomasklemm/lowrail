Active Record's new `default_order` query method from #39525 is [delegated from every model](https://github.com/rails/rails/blob/088fc0cf61e4ba0c7987decafacc69adb3e22eec/activerecord/lib/active_record/querying.rb#L15-L24), so `ActiveRecord::Base` responds to it and `Object` doesn't. For such a name [`dangerous_class_method?`](https://github.com/rails/rails/blob/088fc0cf61e4ba0c7987decafacc69adb3e22eec/activerecord/lib/active_record/attribute_methods.rb#L273-L285) is true, so `scope :default_order` now [raises `ArgumentError`](https://github.com/rails/rails/blob/088fc0cf61e4ba0c7987decafacc69adb3e22eec/activerecord/lib/active_record/scoping/named.rb#L202-L206) when the model loads, as in [fat_free_crm 0.28.0](https://github.com/fatfreecrm/fat_free_crm/blob/1f3dd674f30b1fb3979301985ed77ddfdccb5148/app/models/polymorphic/version.rb#L18) and [otwarchive (master)](https://github.com/otwcode/otwarchive/blob/452391b648f2fb06b55c36133812449747634504/app/models/language.rb#L12).

A model's own `default_order` class method still runs on the model. On a relation, the new [`Relation#default_order`](https://github.com/rails/rails/blob/088fc0cf61e4ba0c7987decafacc69adb3e22eec/activerecord/lib/active_record/relation/query_methods.rb#L946-L951) takes precedence over [delegation to the model](https://github.com/rails/rails/blob/088fc0cf61e4ba0c7987decafacc69adb3e22eec/activerecord/lib/active_record/relation/delegation.rb#L124-L137), and without arguments it [raises](https://github.com/rails/rails/blob/088fc0cf61e4ba0c7987decafacc69adb3e22eec/activerecord/lib/active_record/relation/query_methods.rb#L2631-L2633), as in [danbooru's pool search (master)](https://github.com/danbooru/danbooru/blob/03652f924fcec5d970c771024ba061e8a43d6d00/app/models/pool.rb#L83).

This adds a section to "Upgrading from Rails 8.1 to Rails 8.2" that shows both errors and says to rename the scope or class method.
